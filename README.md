# Sistema básico de ventas con PHP SQLite y Bulma

## Requisitos

- PHP 8.1 o superior
- Extensión PDO SQLite habilitada

## Ejecución en Laragon

1. Copiar la carpeta `tarea_mvc_ventas` dentro de `C:\laragon\www`.
2. Iniciar Laragon.
3. Abrir `http://localhost/tarea_mvc_ventas/` en el navegador.
4. Registrar una venta válida con `P001` y cantidad `3`.
5. Intentar una venta rechazada con `P002` y cantidad `7`.

La base de datos se crea automáticamente en `data/ventas.sqlite`.
